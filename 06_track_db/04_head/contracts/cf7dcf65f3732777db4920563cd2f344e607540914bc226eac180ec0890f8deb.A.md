# Track DB Head · Context Head · Selective Retrieval Contract

## 1. Track DB Unit

```text
One Track DB
=
GitHub에 등록된 하나의 Result.Data Document
=
Database 성격을 가진 하나의 문서
```

```text
TrackDB Branch ≠ One Track DB
Directory ≠ One Track DB
Aggregate Index ≠ One Track DB
```

## 2. Full Document를 전부 읽지 않는다

```text
All Full Track DB Scan
→ Context Window Saturation
→ Work-State Formation Failure
```

```text
Head Root Index
→ Relevant Hash-prefix Shard
→ Relevant Head Object
→ Selected Full Track DB Document
```

## 3. Head와 Context Head

```text
Track DB Full Document
→ 전체 Result.Data·Source·Process·Relation·Conflict·Unresolved 상태
```

```text
Head ≠ Track DB
```

## 6. Root Index and Hash-prefix Shards

```text
HEAD_INDEX.json
→ 사용 중인 Hash-prefix Shard 경로만 제공
```

```text
Track DB Hash 첫 두 Hex
→ 해당 Shard File
```

```text
72... → shards/72.json
9d... → shards/9d.json
```

Shard는 Track DB Hash·Head Object Hash·Path·Subject·Keyword subset만 가진다.
전체 요약은 Head Object에만 둔다.

## 7. Selective Retrieval Rule

```text
Query·Assignment·Directive
→ Keyword·Subject·Relation Key 형성
→ Root Index 읽기
→ 관련 Shard만 읽기
→ 관련 Head만 읽기
→ 필요한 Full Track DB만 읽기
```

Full Document Required:

```text
Exact Source Evidence
Result.Data Cell
Correction·Conflict·Unresolved 세부내용
Lineage·Process 역검산
Head 요약만으로 대상구분 불가
```

Head만으로 최종 사실판정·Exact Quote·Correction 판정·Source URL 확인을 하지 않는다.

## 8. Head Creation

```text
Full Track DB Exact Bytes Verify
→ Metadata·Final Verdict·Counts 추출
→ Head + Context Head 생성
→ Head Byte Freeze
→ SHA-256
→ <head-hash>.A.json
→ Prefix Shard Append
→ Root Index 확인
```

Track DB 본문을 수정하지 않는다.

## 9. Head Update and Lineage

```text
Old Track DB → Old Head
New Track DB → New Head
```

Old Head를 덮어쓰지 않는다.

```text
Old Head ─ SUPERSEDED_BY → New Head
```

## 10. Stale Head Gate

```text
Head track_db.hash ≠ Full Document Filename Hash
Head path File Missing
Full Document Exact SHA-256 ≠ Head track_db.hash
Head Filename Hash ≠ Head Exact Bytes
Root Index → Shard → Head Relation Broken
```

```text
HOLD_TRACK_DB_HEAD_RELATION_FAILURE
```
